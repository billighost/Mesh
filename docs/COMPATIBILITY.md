# Agent & Platform Compatibility Matrix

This document provides transparent, verifiable evidence for Mesh Context Layer integrations across supported AI coding agents and operating environments.

Every adapter is verified at two levels:
1. **Automated test**: Comprehensive regression tests run on CI across Windows, macOS, and Linux verifying file paths, JSON schema preservation, skill symlinking/copying, and rules block injection.
2. **Verified against the real agent (version + date)**: End-to-end verification in a live, running agent session confirming that MCP tools, skills, and memory recall are recognized and invoked.

## How to Reproduce & Verify Each Adapter

You can reproduce the exact configuration files generated by Mesh for each agent using the commands below. Use `--dry-run` to preview file diffs safely without writing changes, or `--apply` to write them.

### 1. Claude Code
```bash
# Preview changes (user scope):
mesh install claude-code --dry-run

# Apply configuration (user scope):
mesh install claude-code --apply

# Project-level configuration:
mesh install claude-code --project --dir . --apply
```
**Verification in live agent:** Run `claude`, run `/mcp`, and confirm `mesh` tools (`mesh_recall`, `mesh_learn`, etc.) are listed and active.

### 2. Claude Desktop
```bash
# Preview changes:
mesh install claude-desktop --dry-run

# Apply configuration:
mesh install claude-desktop --apply
```
**Verification in live agent:** Start Claude Desktop, open Settings -> Developer, and confirm `mesh` displays a green active status.

### 3. Antigravity
```bash
# Preview changes:

# Apply configuration:

# Project-level configuration:
```

## Unverified Adapters Awaiting Real-Agent Details

Per repository verification policy, adapter flags in `mesh/installer.py` maintain `verified=False` until verified against live agent releases.

The four adapters/scopes requiring live version and date confirmation are:
1. **`gemini-cli`**: Adapter writes `~/.gemini/mcp.json`. Official Gemini CLI releases alternate between `settings.json` and `mcp.json`.
2. **`windsurf` (project scope)**: User-scope (`~/.codeium/windsurf/mcp_config.json`) is verified; project-scope (`.windsurf/mcp_config.json`) requires live agent confirmation from Codeium documentation.
3. **`opencode`**: Schema requires `{"mcp": {"servers": ...}}` in `opencode.json`; requires confirmation against current OpenCode release.
4. **`codex`**: MCP config path (`~/.codex/mcp.json`) requires confirmation against official OpenAI Codex CLI tooling.

To verify and flip `verified=True` for any adapter, submit the tested agent version, OS, and verification date.
